MATHEMATICAL PROOF INCLUDED

In-Place Non-Clobbering Invariant Theorem ($r_k \ge w_k$)

When decoding Base64 in-place directly into caller buffers (zero allocations), the read cursor $r_k$ is mathematically proven to strictly lead write cursor $w_k$ at every transition step:

AVX-512: Δr = 64, Δw = 48 &implies; Δr - Δw = 16 > 0
AVX2: Δr = 32, Δw = 24 &implies; Δr - Δw = 8 > 0
WASM / SSSE3: Δr = 16, Δw = 12 &implies; Δr - Δw = 4 > 0
Scalar: Δr = 4, Δw ≤ 3 &implies; Δr - Δw ≥ 1 > 0

Conclusion: $r_k - w_k$ is monotonically non-decreasing. Unread bytes cannot be overwritten. See SAFETY.md for the formal peer-reviewed proof.

API Ergonomics

Zero-Cost Rust Idioms

From zero-allocation in-place decoding to async Tokio streams and compile-time constants.

// Zero-alloc in-place decoding: Decodes directly into the input buffer!
use hyper64::{decode_in_place, STANDARD};

let mut packet = b"SGVsbG8sIEdMQVNUT1Ih".to_vec();

// 0 bytes of heap memory allocated. Guaranteed by mathematical invariant.
let decoded = decode_in_place(&mut packet, &STANDARD)?;
assert_eq!(decoded, b"Hello, GLASTOR!");
